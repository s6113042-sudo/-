# 流金理財 GoalFlow

> 結合遊戲化激勵與區塊鏈技術的個人財務管理應用

---

## 專案簡介

**流金理財** 是一款以理財習慣養成為核心的 Web 應用程式。透過目標追蹤、記帳記錄、每日簽到連續獎勵，以及寵物成長等遊戲化機制，幫助使用者建立長期儲蓄習慣。後端整合 Sui 區塊鏈，可連結加密貨幣錢包並記錄鏈上交易。

---

## 功能亮點

### 💰 財務管理
- **收支記錄**：快速新增收入與支出，支援 12 種交易分類
- **交易註釋**：點擊任意紀錄可展開並編輯個人備註
- **每日預算追蹤**：即時計算今日剩餘可用額度，超支自動提醒
- **月曆記帳**：以月曆視圖瀏覽每日收支狀況，結合鏈上資料雙軌顯示

### 🎯 智慧目標
- **財務目標設定**（上限 1 個）：設定目標金額與截止日期
- **智慧分配算式**：依剩餘時間自動計算最佳儲蓄比例，確保：
  - 生活費 ≥ 30%
  - 緊急備用 ≥ 5%
  - 落後進度時自動加入安全緩衝，抵禦市場波動
- **四類分配視覺化**：點擊目標可展開「生活費 / 目標儲蓄 / 緊急備用 / 投資理財」佔比與進度條
- **每日 00:00 自動刷新**（台灣時間）

### 🏆 任務與成就
- **經驗值系統**：第 1 級需 200 XP，每升一級門檻 +50 XP
  - 記帳：每次 +5 XP，單日上限 +20 XP
  - 存款：每 1,000 元 +1 XP
  - 完成目標：< NT$10,000 → +10 XP；≥ NT$10,000 → +25 XP
- **寵物進化之路**：
  | 等級 | 型態 | 名稱 |
  |------|------|------|
  | Lv.1 | 🥚 | 存錢蛋 |
  | Lv.3 | 🐣 | 破殼新芽 |
  | Lv.6 | 🐥 | 理財小雞 |
  | Lv.10 | 🐓 | 財富雄雞 |
- **連續記帳獎勵**：七天進度條，連續 7 天登入可開啟寶箱，獲得 0.01 ~ 1 USDC（期望值 ≈ 0.3 USDC）
- **成就徽章**（6 枚）：
  | 徽章 | 達成條件 |
  |------|---------|
  | 🌱 新手上路 | 第一次登入 |
  | 🎯 目標設定者 | 第一次設定目標 |
  | 📝 記帳達人 | 第一次記帳 |
  | ⏰ 時間管理師 | 完成一個目標 |
  | 💰 儲蓄冠軍 | 累積存款 10,000 元 |
  | 🏆 自律大師 | 連續登入 100 天 |

### 🔗 區塊鏈整合（Sui Network）
- 連結 SLUSH 等 Sui 錢包
- 自動同步鏈上交易紀錄
- 月曆介面顯示鏈上交易明細（Gas Fee、物件變動）

### 🖥️ 側邊欄快捷
- **每日簽到鍵**：一鍵簽到，連續記帳天數 +1
- **訂閱鍵**：點擊訂閱，狀態持久化

## 快速開始

### 環境需求
- Node.js 18+
- npm 或 pnpm

### 安裝與啟動

```bash
# 克隆專案
git clone https://github.com/s6113042-sudo/-.git
cd -

# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev
```

開啟瀏覽器前往 [http://localhost:3000](http://localhost:3000)

### 建置生產版本

```bash
npm run build
npm start
```

## 資料儲存

開發模式使用 `localStorage`，以下為儲存鍵值：

| 鍵值 | 內容 |
|------|------|
| `gf_app_state` | 使用者設定檔 & 錢包狀態 |
| `gf_goals` | 財務目標 |
| `gf_transactions` | 交易紀錄 |
| `gf_rewards` | 等級、XP、成就、連續天數 |
| `gf_allocation` | 資金分配計畫 |
| `gf_recurring` | 固定支出 |
